## Correcciones de interpretación
- Un **router no fabrica créditos gratis**: otro proveedor o modelo puede tener su cuota o coste.
- **Reducir contexto** puede perder información útil si no se valida; la compresión se mide por calidad.
- **Memoria persistente** no significa recordar todo correctamente; hay que controlar qué se guarda.
- Una skill de diseño no garantiza resultado profesional. «Nunca alucina» no se prueba por mostrar una herramienta de búsqueda; «cualquier página» no acredita acceso universal ni permisos.
- «Software libre» no vuelve gratuitos a todos sus proveedores ni elimina cuotas. «Plan de 20 frente a 100» y «el límite apenas se consume» son afirmaciones comerciales **no comprobadas**; pasar trabajo a otro servicio no demuestra consumo cero.

## Receta paso a paso (propuesta nuestra)
1. Trátalos como **candidatos**, no como instrucciones: no instalar duplicados desde estas referencias ni cambiar configuraciones.
2. Para evaluar, mide consumo en ambos lados, tiempo de coordinación y calidad de lo entregado.
3. Reparto de trabajo propuesto para un futuro plugin: **especificación acotada → código → prueba en Premiere → revisión del resultado real**.
4. Para tus proyectos encajan tres fases: investigar referencia, leer contenido y comprobar interacción del producto; **no equivale** a ver cada video ni sustituye la transcripción e inspección que ya se hace.
5. Verifica precio, cuotas, licencias y disponibilidad en la fuente oficial **antes de recomendar**.
